🎬 React Movie Finder

Application créée dans le cadre du cours ReactJS – Master 1 – Ynov 2025/2026.
Le projet a été réalisé en React + Vite et communique avec l’API TheMovieDB (TMDB).

🚀 Installation & lancement du projet
1) Cloner le projet
`git clone https://github.com/kerael7/react-movie-finder.git`

`cd react-movie-finder`

2 ) Installer les dépendances

`npm install`

3 ) Lancer l’application en développement :

`npm run dev`

Puis accéder à :

http://localhost:5173

5 ) Générer la version de production (build)
`npm run build`

6 ) Prévisualiser le build
`npm run preview`
